# Security policy

## Supported versions

Eos is pre-1.0. Only the latest published release of `@eos-ui/vue` and `@eos-ui/tokens` receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Report it privately with [GitHub private vulnerability reporting](https://github.com/Dame-G/eos/security/advisories/new) (the Security tab of the repository, then "Report a vulnerability").

Include the package and version, what you found, and steps or a minimal reproduction.

## What to expect

This is a small project run by one maintainer, so these are goals, not guarantees:

- Acknowledgement within 7 days.
- An assessment and a plan within 14 days.
- A fix released as soon as it is ready, with credit in the advisory if you want it.

Accessibility bugs are not security issues. Report them as normal issues.
